Attribute Pivot Viz — Rendering Preview

Static preview demonstrating the pivot rendering logic including the new optional numeric Measure slot. The actual plugin runs inside Oracle Analytics Cloud.

Scenario 1 — Basic: 1 Row dim × 1 Column dim, categorical values multi-value sub-rows

Data columns: Region (Rows) | Quarter (Columns) | Project Status (Values)
No Measure slot used — behaviour unchanged.

Scenario 2 — Categorical value + numeric Measure NEW: Measure slot

Data columns: Region (Rows) | Quarter (Columns) | Project Status (Values) | Revenue ($k) (Measure)
The numeric measure appears in blue below the categorical value. No binning occurs.

Scenario 3 — Measure only (no categorical Values) NEW: Measure slot

Data columns: Product (Rows) | Region (Columns) | Units Sold (Measure)
When there's no categorical Values column, the measure fills the cell on its own.

Scenario 4 — Two value columns + Measure multi-val columns NEW

Data columns: Product (Rows) | Region (Columns) | Status + Owner (Values) | Budget ($k) (Measure)
Measure appears in the last value column's cell only.
